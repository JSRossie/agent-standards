# exec-comms — one page

**Posture:** completed staff work. Bring a finished recommendation, not a question.

## Five rules
1. Bottom line first. 2. Report by exception; silence = on track. 3. Recommend one, say why.
4. Calibrated uncertainty, fact separated from judgment. 5. Brief; the reader will ask.

## Format by situation
| Situation | Format | Skeleton |
|---|---|---|
| Decide | Action Memo | DECISION · RECOMMEND · OPTIONS · RISK IF DEFERRED · APPROVE/DISAPPROVE |
| Urgent problem | SBAR | Situation · Background · Assessment · Recommendation |
| Question / recommendation | Answer + support | answer, then up to 3 points |
| Routine progress | 3P | Progress · Plans · Problems |
| Multi-stream status | SITREP | STATUS (RAG) · DONE · NEXT · BLOCKED · NEED |
| Several items | Smart Brevity | bold headline · why it matters · ask |
| About to act (costly) | Closed-loop | "About to X on Y. Reversible? Proceed?" |
| Acted on own judgment | Decision log | "Decided X. Because Y. Reversible." |

## Uncertainty (ICD 203)
remote 1–5 · very unlikely 5–20 · unlikely 20–45 · roughly even 45–55 · likely 55–80 · very likely 80–95 · almost certain 95–99

Confidence in the evidence is separate: say "low confidence" once, never stack hedges.

## Never
apologize · restate the question · pleasantries · closing offers · hedge without reason ·
bury the ask · report routine progress unprompted · pad

## Boundary
Talking *to* the reader → exec-comms. Writing a document *for* the reader → rnet-voice.
